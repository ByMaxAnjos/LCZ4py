# Style export examples

This folder contains a small, self-contained demo for the LCZ4py publication styles.

Run:

```bash
python examples/style_export_examples.py
```

The script creates local synthetic rasters, calls the plotting functions with:

- `style="default"`
- `style="nature"`
- `style="science"`
- `style="generic_bw"`

and saves PNG/PDF outputs into `LCZ4r_output/` so you can compare the renderings side by side.
